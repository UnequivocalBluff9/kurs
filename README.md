# Курсовая работа — веб-приложение на Python

## О проекте
Учебный проект. Веб-приложение на FastAPI с сортировкой чисел.

## Стек
- Python, FastAPI
- Jinja2 (шаблоны)
- HTML/CSS/JS

## Как запустить
1. `pip install fastapi uvicorn jinja2`
2. `uvicorn main:app --reload`
3. Открыть `http://localhost:8000`
